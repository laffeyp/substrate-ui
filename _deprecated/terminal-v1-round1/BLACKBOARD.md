## Drift watchlist

*Agent maintains. Patterns to monitor across sprints.*

- **DW-1 (from Sprint 004 adversarial pass).** `activate()` fires on `.tabbar` click but not on keyboard focus events (Space/Enter on a focused tab button). If accessibility becomes a concern before ship, add a keydown handler. Not gating any current sprint.
- **DW-2 (from Sprint 006 adversarial pass).** State-preservation assertion after tab-switch uses `.textContent.includes()`, which passes on duplicated appends. If `renderTerm()` starts firing on tab-swap for any reason, duplicates would slip. Tighten to line-count assertion when Sprint 007 wires `/api/agent` (multi-turn will make counts non-trivial anyway).
- **DW-3 (from Sprint 006, A7-related).** Capture script has grown to include structural assertions (asymmetry check, prompt-color decode, fixture hash) that A7 says belong in the CI-gated E2E. If capture script grows one more sprint, factor a shared decoder helper both scripts import; move the assertions to the E2E where CI gates them.
- **DW-5 (from Sprint 008 workflow).** The parent substrate-ui `server.py` and any topology it imports can drift out of sync with a long-running background server. When either changes, restart the server before running the harness. Consider a Sprint-N.INT gate that includes an explicit restart step.
- **DW-4 (from Sprint 007 adversarial pass).** The picker `change` handler's `if (!v) return` guard protects against an empty-value change event, but the harness does not exercise a synthetic empty-value change to prove the guard works. If a later sprint edits the change handler, a regression that removes the guard would not be caught. Add a targeted synthetic-event test when Sprint 008 wires `/api/agent` (which will care deeply about STATE.term.model being non-empty).

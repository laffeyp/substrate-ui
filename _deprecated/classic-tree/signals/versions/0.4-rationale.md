# Rationale — signal vocabulary v0.4

*New file per no-in-place-edits. `0.3-rationale.md` stays on disk. v0.4 folds four merited findings from `process/reviews/REVIEW-2026-08-16-sdd-instrumentation-comprehensive.md`: S1 (entity_merges ratification), S2 (halt-proposal disposition + TURN_SUBMITTED.turn_index promotion), M2 (frame-monotonic invariant), M3 (SESSION_INIT-first + SESSION_ENDED-last). ## Intent + scope

Substrate-ui carries 53 tags across 12 categories, covering both the console (`web/app.ts`) and the studio (`web/studio.ts`). v0.4 tightens three grader-enforced invariants into vocabulary-locked invariants, promotes one payload field from optional to required, and records the retroactive ratification of five entity_merges that arrived in prior versions without an explicit proposal step. No behavior changes at the emit boundary; two additional grader checks fail on drift the prior versions accepted.

## Per-change ledger (v0.4 vs v0.3)

### 1. `TURN_SUBMITTED.turn_index` promoted from optional to required (S2 fix)

`signals/versions/0.3.json` had `TURN_SUBMITTED.optional_payload: ["turn_index"]`. The 2026-08-15 halt-proposal recommendation named the promotion; the halt sat unratified while sprints 030/031/032 dispatched. v0.4 closes the halt. Evidence: `web/app.ts:342` sets `turn_index = Math.floor(STATE.term.chat.convo.length / 2)` on every call — a total function of the convo state, never omitted. The Sprint 025 fixture carried it on the one turn it exercised; the Sprint 032 fixture inherits the same emit site. Promotion is safe.

### 2. Frame-monotonic invariant locked (M2 fix)

`tools/capture-grade.ts § checkFrameMonotonic` enforced this across 214–286 pane-render paints in every Wave-1 fixture. v0.3 invariants[] did not list the rule; v0.4 does: *"Frame is monotonically increasing across every pane-category tag in a capture (the shared _paintFrame counter never decreases)."* The grader now enforces a locked rule, not a grader-only convention.

### 3. SESSION_INIT-first + SESSION_ENDED-last locked, absolutely (M3 fix)

v0.3 invariants[] said "SESSION_INIT is the first signal in any capture" and "SESSION_ENDED, when it fires, is the last signal." `containsInOrder` verifies position within EXPECTED_ORDER — a supersequence check that a random capture with a stray signal before SESSION_INIT would pass. v0.4 splits the rules into absolute-position invariants and adds `checkSessionBookends` in the grader to enforce them against the whole capture.

### 4. Retroactive entity_merges ratification recorded (S1 fix)

v0.2 declared four entity_merges (Record/Run, Topology/Topology, AgentRun/Run, Event/Envelope). v0.3 added the fifth (Spec/authored_topology). None of the five passed through `ENTITY_MERGE_PROPOSED` per `sdd-kit-2/grammar/PRINCIPLES.md`. `REVIEW-2026-08-16-sdd-instrumentation-comprehensive.md § S1` flagged the discipline breach.

v0.4 adds an `entity_merges_ratification` block naming the two Architect directives that ratified the merges post-hoc:
- "fix all review findings that have merit" (2026-08-16) ratified the four v0.2 merges.
- "Studio must be instrumented; it is one thing, not two" (2026-08-16) ratified the fifth.

The block also names the discipline going forward: proposal-then-ratification at authoring time for any new merge, not silent inclusion followed by retroactive record.

### 5. Halt-proposal dispositions (S2 fix, remaining three)

The 2026-08-15 halt named four v0.2 proposals; #3 (`TURN_SUBMITTED.turn_index required`) lands as change #1 above. The other three are dispositioned here on the record:
- `NEW_TAG_PROPOSED: INSPECTOR_RENDERED` — **defer**. The inspector still renders as one innerHTML block; no sub-panes have surfaced. Revisit if a sub-pane split lands.
- `NEW_TAG_PROPOSED: FRAME_RENDERED` — **defer**. The `_paintFrame` counter already grades monotonic across six pane-render tags; a sampled ambient-stratum tag would double-cover the same signal.
- `TAG_SPLIT_PROPOSED: TOPOLOGY_LAUNCHED vs BUNDLED_LAUNCHED vs AUTHORED_LAUNCHED` — **resolved without a split**. The authored-build path landed at Sprint 032 as `SPEC_BUILT` in the `studio` category. `TOPOLOGY_LAUNCHED` continues to name the bundled-launch path only. No split needed.

## Dual-contract audit — the nine v0.3 studio tags

Each studio tag pairs a user action (behavior) with a captured signal (view). The table names the pairing that ties the two together.

| Tag | Behavior it observes | View surface | Pair or invariant |
|---|---|---|---|
| SPEC_ROW_ADDED{kind} | User clicked #addProducer, #addView, #addTrigger, or #addRoute | The new row appended to its section | SPEC_ROW_ADDED{kind: K} followed within the same event loop by DOM insertion of a `.row` under `#Ks` (checked structurally in the studio e2e, not the signal fixture). |
| SPEC_ROW_REMOVED{kind} | User clicked the .rm affordance on a row | The row is removed from the DOM | Similar to above; SPEC_ROW_REMOVED{kind: K} follows one SPEC_ROW_ADDED{kind: K} within the fixture's window. |
| CANVAS_TOGGLED{to} | User clicked #vForm or #vCanvas | `#formView` and `#canvasView` display flip | Idempotent-click silent by design (setView only emits on an actual mode change). |
| SPEC_VALIDATE_REQUESTED / SPEC_VALIDATED{valid} | User clicked #validateBtn | The `#out` block gets a ● valid or ● invalid line | Vocab invariant: SPEC_VALIDATE_REQUESTED followed within 5 s by exactly one SPEC_VALIDATED. |
| SPEC_BUILD_REQUESTED / SPEC_BUILT{run_name, status} / SPEC_BUILD_REJECTED{reason} | User clicked #buildBtn | The `#out` block gets a ● built line and a "view the run in the console" link | Vocab invariant: SPEC_BUILD_REQUESTED followed within 30 s by exactly one SPEC_BUILT or SPEC_BUILD_REJECTED. |
| CONSOLE_LINK_FOLLOWED{run_name} | User clicked the `.consolelink` anchor | A new tab opens on /?record=<run_name> (target="_blank") | Emit fires from an addEventListener before the anchor default; the studio's signals buffer survives. |

## Project-specific overrides (unchanged)

- Emitter throws on unknown tags and on missing required fields; `payload_types` foreign-key enforcement is namespace-split (substrate.* values checked against closed set; application-namespace values checked as non-empty strings).
- Parity gate scans `web/` + `harness/` + `tools/` for `emit("TAG", ...)` sites; every found emit must be a locked tag.
- `signals/versions/current.json` is a symlink to the currently-locked version file; loader and parity gate both read from it.

## Small findings

**F-1 — `payload-check.js` silently skips tags that lack a Layer 2 schema.** `tests/harness/payload-check.js:33-34` reads `const schema = s[sig.kind]; if (!schema) continue;`. If a tag is present in Layer 1 but its Layer 2 schema is absent or misnamed, the payload check passes it. Layer 2 is supposed to cover all 108 tags (per `signals/0.1-rationale.md § Layer 2 count check` — `107 payload_schemas keys total ... no orphaned schema`), so this is a defensive skip today. Cheap tightening: at module load, assert `Object.keys(SCHEMAS)` is a superset of `layer_1_lexical.tags[].name`; fail loud if a Layer 1 tag has no Layer 2 entry. Closes the exact class Layer 6 review O2 hit (misassigned linkage) at the harness gate.

**F-2 — `tonal-checks.js assertNoWrap` inspects only `.label`.** `tests/harness/tonal-checks.js:33-38` queries `document.querySelectorAll(".label")`. `src/render/Pane.tsx` and `src/render/PaneHeader.tsx` may render session-name spans, driver-chip labels, and workspace chips under other class names. Suggest either (a) widen the selector to a data attribute (`[data-tonal-label]`) every label carries, or (b) grep the render tree at test setup and warn if a header element lacks the class. The rule is D32 (labels never wrap); the check should read D32's actual scope, not just its literal name.

**F-3 — `DELEGATE_DEPTH_CAP_REFUSED` fires from two sites for the same refusal.** `ShellReducer.ts:396-398` emits the tag when the user attempts a third descent shell-side. `ShellReducer.ts:596-600` emits the same tag when a delegate `ToolResult` arrives carrying substrate's max-depth error string. Both can fire for one logical refusal (user attempts descent, substrate also raises). Layer 5 pairing tolerates duplicate `from` — the trace passes — but a client counting refusals double-counts. Consider: keep one source (envelope-driven from the substrate ToolResult) and treat the shell-side attempt as a UI-only refusal without emit; or keep both and dedupe by `tool_call_id`.

**F-4 — `TURN_SUBMIT_ERR` restores pane to `PARKED` unconditionally.** `ShellReducer.ts:646-648` sets `status: PaneStatus.PARKED` on any `TURN_SUBMIT_FAILED`. If the failure reason is `session_ended` (the SessionEndedMidTurn typed exception), the pane should reflect ended, not parked — otherwise the next PROMPT_SUBMITTED tries again against a dead session. Small; the bridge would refuse on retry, but the pane surface lies briefly.

**F-5 — Inspector harness accepts one unbalanced open at teardown.** `tests/harness/e2e_inspector.js:107` reads `Math.abs(totalOpen - totalClose) <= 1`. The comment names why (the app closes with inspector still open on row 1). Layer 5 pairing tolerates it. The honest fix is a teardown step that fires the closing action before app close, so the trace closes cleanly. Cheap; strictly better than a `<= 1` tolerance.

**F-6 — `bridge-reasons.json` is a source of truth outside `signals/0.1.json`.** `tests/harness/e2e_delegate_cap_fanout.js:53` reads `signals/bridge-reasons.json` for the delegate error prefix substring. Any prefix change in substrate needs two files touched here. Not a bug (the file lives under `signals/` and the harness fails loud on a substrate rename via `assertDelegatePyErrorStringHolds`), but the standing rule "vocabulary as contract, single-sourced" argues for either folding the substring set into `signals/0.1.json § layer_7_evidence` as a substrate cross-reference constraint, or documenting `bridge-reasons.json` as the second half of the vocabulary. Pick one and name it.

## Lessons worth pinning as KIT_DIARY entries (H19–H22 candidates)

None of these live in `KIT_DIARY.md` today. Each is grounded in a specific commit or file. Suggested numbering follows H18.

- **H19 (candidate). Vocabulary drift closes mechanically by codegen, not by discipline.** Evidence: commit `0b8623e` "Tag const generated from Layer 1 — zero raw tag literals" + commit `e9c06bc` "SDD audit — raw-string cleanup + Layer 5 assertion actually asserts now" + `src/observability/tags.ts:128-133` load-time drift guard. Class: hard rule 2 was already stated; H17 stated payload-shape drift is the same class; H19 is the mechanism — generated constants + load-time count check + shared harness assertion — closes the class by construction. A generated file with a runtime drift guard is worth naming as its own kit technique.
- **H20 (candidate). Layer-7 slot names drift by punctuation and only a codegen sweep catches it.** Evidence: the BLACKBOARD ## Surfaced entry for Sprint 024 records that "the reducer had `header_popover` (underscore) while Layer 7 has `header-popover` (hyphen); the codegen forces the vocabulary's spelling." Class: even under a locked vocabulary, a hyphen/underscore split between the JSON and the code compiles and passes tests until the codegen sweep runs. Kit implication: any Layer-N string that appears in both the JSON and the code needs a generated projection, not two hand-maintained copies. Generalizes H17/H19 from tag names to any Layer-N identifier.
- **H21 (candidate). A standing shared harness library beats sprint-per-sprint copies.** Evidence: commit `8e9f231` "retrofit all 19 sprint harnesses onto the shared library" + `tests/harness/lib/harness.js` scaffold. Class: Sprint 048's reshape (per REVIEW-2026-09-10 §Tonal rules) generalizes — any check that should run on every sprint's harness belongs in a shared library called by every `e2e_*.js`, not restated per sprint. Once the library exists, adding a new class of check touches one file and every sprint inherits it (the Layer 5 assertion the same audit landed is the second example).
- **H22 (candidate, meta). H18 recurred within one sprint of being written.** Evidence: KIT_DIARY H18 landed 2026-09-10 diagnosing the exact "code shipped, card status unflipped, KIT_DIARY silent, ## Built empty" class; sprints 018–024 land the same pattern between 2026-09-10 and 2026-09-11. Class: naming a hygiene lesson in the diary does not install it as a gate. The four sprint-close artifacts need a mechanical check that runs at sprint-close time — a pre-commit hook that fails if the commit message names a sprint whose card is still `pending`, or a `npm run close-sprint <NNN>` helper that flips the card, adds a Built paragraph template, and adds a KIT_DIARY entry stub. Discipline is not what H18 taught; the fixture that enforces it is.

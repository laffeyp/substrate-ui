# Sprint 194 — pixel comparison for the move off dc-runtime

## scope

Author `harness/pixel/diff.ts` and add `pixel:capture` and `pixel:diff` to `package.json`, with `pixelmatch` 8.0.0 as a devDependency. `npx tsx harness/pixel/diff.ts <baseline> <candidate>` compares every PNG in `captures/pixel/<baseline>/` with the file of the same name in `captures/pixel/<candidate>/`, decoding with `harness/pixel/png.ts` and counting differing pixels with `pixelmatch` (threshold 0.1, anti-aliased pixels ignored). A file fails when it is missing, when its size differs, or when more than 0.1% of its pixels differ; each failing file's diff image is written to `captures/pixel/<candidate>/diff/`.

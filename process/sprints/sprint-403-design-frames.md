## scope

Author `harness/design/render_frames.ts`. Run with frame ids (`npx tsx harness/design/render_frames.ts 24a 24h 16c`), it opens `../design/received/handoff 5/sheets/Substrate Shell Directions v11.dc.html` in Chrome through Playwright, and writes each frame's card (`[id="<frame>"] .dv-card`) as a PNG at device scale 1 to `runs/design/sheet-v11/<frame>.png`, printing each frame's width and height. Every later editor card's Track 2 reads its screenshot beside these files. It exits 1 naming any frame id the sheet lacks.

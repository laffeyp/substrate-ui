# v0.16 rationale — the vocabulary's names generated for the code (sprint 363)

*Locked 2026-11-07. Supersedes `0.15.json`; 88 tags, 87 live. Earlier rationales cover everything not named here.*

## The change

**`P-0.16-TYPED-NAMES`** (`TAG_DEPRECATION_PROPOSED`). Every tag name and enum value used to be a raw string, typed out by hand at each call site. Three hand-written checkers read the prose field types at runtime and wrote `SIGNAL_REJECTED` for a broken emit.

`scripts/gen_signals.py` now generates the code's names from this file:
- **TypeScript** (`web/vm/signals.gen.ts`, `electron/signals.gen.ts`): string enums `Signal` and one per enum field, plus `SignalPayloads`, each tag's payload type. `emit` and `mainRecord` take only `Signal` and that tag's payload, and a plain string cannot stand in for an enum member. So a wrong tag, a missing or extra field, or a raw value fails `tsc`.
- **Python** (`signals_gen.py`): `StrEnum`s for the server.

The runtime checkers are gone, and with them:
- `SIGNAL_REJECTED`, retired;
- E2, the cut of long reasons;
- E5, the number ranges;
- E6, the per-build posture.

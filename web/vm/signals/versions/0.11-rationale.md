# v0.11 rationale — the server's domain signals (sprint 357)

*Locked 2026-11-06. Supersedes `0.10.json`; still 88 tags. Plan `process/planning/2026-11-05-sdd-signals/`, item 4, the area "server routes as domain events". Earlier rationales cover everything not named here.*

## The changes

**`P-0.11-SHAPE-KERNEL`.** `SESSION_CREATED.workspace_shape` is the kernel's `WorkspaceShape`: `flat | worktree | isolate` (`../substrate/src/substrate/topologies/session_registry.py`). v0.7 wrote `flat | worktree | sandbox | path`, two values the kernel never sends and without `isolate`, which `server.py` sets for every isolated session. Workspace is kernel-homed, so its values are the kernel's. Found when `tests/test_daemon_control_determinism.py::test_isolate_create_parity` failed with the trace on.

**`P-0.11-AREA-UNROUTED`.** `API_REFUSED.area` and `SERVER_FAULTED.area` gain `unrouted`, for an `/api/` path that no route serves. The window still calls `/api/validate` and `/api/build`, which the server deleted on 2026-10-08 (`1e326db`). Without the value, those refusals could not be written.

**`P-0.11-CAUSE-SITE`.** `API_REFUSED.cause` is the refusing handler and line, `function:line` in `server.py`. The 133 `_error` calls and the direct 409, 410 and 429 answers carry free text that can hold request content (E1). The site names the line that decided. The text reaches the trace through the window's `*_REFUSED` detail, bounded by E2.

## Where each tag is written

| Tag | Site |
|---|---|
| `API_REFUSED` | `Handler._send`, every `/api/` response of 400 or over |
| `SERVER_FAULTED` | `Handler._fault`, the nine handler boundaries that turned an exception into a 500 |
| `SESSION_CREATED` | `_session_create` and `/api/agent`'s create |
| `TURN_ACCEPTED` | the turn builder each of the two turn paths hands the kernel, under the session's lock, with the turn index |

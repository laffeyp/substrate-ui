# v0.37 rationale — find and replace in the open file

*2026-11-09, sprint 428. Bumps v0.36 to v0.37 (140 tags, 139 live). One proposal: P-0.37-FIND-IN-FILE.*

## Layer 1 — Tags

EDITOR_FIND_QUERIED (regex, case_sensitive, match_count): a find in the open file settled and its matches were counted and marked. EDITOR_REPLACED (scope one | all, count): a replace in the buffer. The query and the replacement stay out of the trace (E1). EDITOR_SEARCH_QUERIED stays the workspace search (⌘⇧F, E8).

## Dual-contract pairing

| Behaviour | View-side counterpart |
|---|---|
| a find (EDITOR_FIND_QUERIED) | the section's `N of M`, the marked matches in the code |
| a replace (EDITOR_REPLACED) | the buffer changed; EDITOR_DRAWN.unsaved |

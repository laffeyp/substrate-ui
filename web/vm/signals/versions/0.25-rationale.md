# v0.25 rationale — emit sites name the code as it is (comment audit)

*Locked 2026-11-08. Supersedes `0.24.json`; 109 tags, 108 live, each unchanged in name, category, stratum, payload, types and note. Earlier rationales cover everything not named here.*

## The change

**`P-0.25-EMIT-SITES`** (Layer 6). An emit site is how an agent reading the trace finds the line that decided a record. A 2026-11-08 audit checked each emit site, entity and rule source, and operator home against the tree. 23 entries named code the tree does not have:

- **20 named `.js` files.** They named `electron/main.js`, `electron/menu.js` or `electron/preload.js`, which have been TypeScript since sprint 363.
- **TOP_BAR_CARD_SET** named `App.tsx setCards`; the method written in v0.24 is `noteCards`.
- **The Server operator** cited `server.py` lines 2466 and 270 for `Handler` and `_daemon_driver_resolver`, which are now at 2646 and 273. The line numbers are dropped, since they move with every edit.
- **LENS_CHANGED and PAGE_DRAWN** gave short paths (`state/meta.ts`; `AssayPage`, `StudioPage`), now written in full.

## Sign-off

Agent-resolved 2026-11-08 (BLACKBOARD). A script checks that every live tag's emit site names a file in the tree and a symbol that file contains; with v0.25 it finds none missing.

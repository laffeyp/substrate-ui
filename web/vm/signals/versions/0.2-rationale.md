# v0.2 rationale — reveal shell vocabulary

v0.2 adds four tags to v0.1's thirty-one, all from UI sprint 176, which gives the app the runs a session starts (kernel K319; research r8 § 3.6). v0.1's tags carry over unchanged.

## The tags

- **RUN_STARTED** (`runs`, event). A `TopologyRunStarted` reached the session's record. The payload carries the run's id, its topology and its sessions with their record roots, so the shell can open one pane per session without a second read. `t` is the record's write time: the shell opens panes only when `t` is under a minute old, so reattaching an old session does not reopen its finished runs.
- **RUN_FOCUS_REQUESTED** (`runs`, event). `/run focus` named a run. The shell focuses its pane, or opens it again if it was closed.
- **RUN_STOP_REQUESTED** (`runs`, event). The server accepted `/run stop`. The run's session ends with reason `caller_stop`, and the caller's model is told at its next step.
- **TURN_REFUSED_VIEW_ONLY** (`turn`, incident). A line was sent in a pane that shows a run's session. Its topology writes that session's messages, so nothing is posted and the pane says why.

## The category

`runs` is new: a run is neither a session nor a record attach, and its three event tags share one subject. The view-only refusal stays in `turn`, beside `TURN_REFUSED`, because it is a turn that was not sent.

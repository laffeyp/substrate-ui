# v0.59 rationale — the right-click menu

*2026-11-11, sprint 457. Bumps v0.58 to v0.59 (153 tags). One proposal: P-0.59-CONTEXT-MENU. Grounds: D94 ("right-click › Add to message"), roadmap r13 E10.4, and the BLACKBOARD decision of 2026-11-11 that the menu is drawn in the page.*

## Layer 1 — Tags

CONTEXT_MENU_OPENED {source, items}, category window. The menu is drawn where the right-click was: a row of the editor's files tree, a tab, a row of the search results, or the code. `items` counts what it offers. No label or path goes in the payload (E1).

CONTEXT_MENU_CLOSED {outcome}, category window: picked, escape, outside or blur. It pairs with the opening. A menu closed without a pick leaves no other trace, and Escape on an open menu must close the menu and not interrupt the turn, which the pair shows.

## Layer 2 — Payload

EDITOR_CHIP_ADDED.how gains `menu`: a chip added by right-click › Add to message.

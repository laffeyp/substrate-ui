## Layer 1 — Tags

INPUT_CHIP_REMOVED: a chip removed before sending, by × or ⌫. EDITOR_CHIP_ADDED, declared since v0.28, is emitted.

## Layer 2 — Payload

TURN_SUBMITTED gains `attachments`, the chips sent with the message; the server's TURN_ACCEPTED counts them too.

## Dual-contract pairing

| Behaviour | View-side counterpart |
|---|---|
| ⌥-click on a file or folder in the tree | EDITOR_CHIP_ADDED; the chip in the input bar |
| × or ⌫ | INPUT_CHIP_REMOVED; the chip gone |
| ↵ with chips | TURN_SUBMITTED.attachments; TURN_ACCEPTED.attachments; the record's UserMessage carries them; the bar empty |

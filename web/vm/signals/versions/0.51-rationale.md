## Layer 2 — Payload

TURN_ACCEPTED gains `by_reference`: the attachments that went as a reference line rather than their content. A binary, missing, unreadable or image file goes this way, and so does a file past the 64 KB a file inlines or the 256 KB a message inlines. With `attachments` it tells, without a path or a text (E1), how much of a message reached the model as content.

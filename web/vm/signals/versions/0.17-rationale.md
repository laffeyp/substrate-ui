# v0.17 rationale — two more causes for a view change (sprint 366)

*Locked 2026-11-07. Supersedes `0.16.json`; 88 tags, 87 live. Earlier rationales cover everything not named here.*

## The change

**`P-0.17-VIEW-CAUSES`** (`PAYLOAD_FIELD_PROPOSED`). `VIEW_CHANGED.cause` named six causes: key, button, menu, split, records_open, close. `web/app/App.tsx` changes the open view on two paths that are none of these:
- **`language`.** `/language`, typed in the input bar, raises the focused pane's `languageOpenTick`. The shell subscription then opens meta on the language lens (UI sprint 172). It is a slash command, not a key, button or menu.
- **`tweak`.** `componentDidUpdate` sets panes or meta from the design tool's `view` prop (`TWEAK_PROPS.view`). The app mounts `App` with no props, so this runs only under the design tool's tweak editor.

Without a value for each, those two changes would go unwritten or be written under a cause that did not make them.

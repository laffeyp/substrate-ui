# v0.54 rationale — the diff base without main

*2026-11-10, sprint 450. Bumps v0.53 to v0.54 (149 tags). One proposal: P-0.54-DIFF-BASE. Grounds: the Architect's report that the editor's text is blue in the app; the installed app's DIFF_READ records (base first_commit); design spec r6 §5; D6; git-diff(1).*

## Layer 2 — Payload

DIFF_READ.base gains two values:
- `head`: a repository with commits but no `main` and no `origin/HEAD` compares with its last commit.
- `no_commit`: a repository with no commit has no base, so no hunks and no dots.

`first_commit` is retired and no longer written. That base, and git's empty tree for a repository with no commit, marked every line written since as added. The centre painted those lines teal, so the text was blue.

## Dual-contract pairing

| Behaviour | View-side counterpart |
|---|---|
| DIFF_READ base no_commit | no `.cm-added` line; no tree dot; the text in its syntax colours |
| DIFF_READ base head | only the lines changed since the last commit drawn teal |

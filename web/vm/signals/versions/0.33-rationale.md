# v0.33 rationale — the buffer's state on the editor's view tag

*2026-11-09, sprint 424. Bumps v0.32 to v0.33 (135 tags, 134 live). Two proposals: P-0.33-EDITOR-DRAWN-BUFFER, P-0.33-BINDING-REQUIRED.*

## Layer 2 — Payload

EDITOR_DRAWN gains required `mode` (the vim mode the status line shows: normal, insert, visual, replace; none under nano or with no file open), `read_only` (the centre takes no typing: an ended session or a view-only pane) and `unsaved` (open files whose buffers differ from the file as read). `binding`, optional since v0.29 until the setting existed, is required on EDITOR_OPENED and EDITOR_DRAWN: sprint 423 built the setting. The pixel anchor gains a third row carrying mode, binding, read_only and unsaved with the same proc_seq (roadmap r8, "the anchor's room").

## Dual-contract pairing

| Behaviour | View-side counterpart |
|---|---|
| the binding chosen in settings | EDITOR_OPENED.binding, EDITOR_DRAWN.binding |
| vim's mode changed (`i`, `v`, Escape) | EDITOR_DRAWN.mode; the status line |
| the session ended, or the pane is view-only | EDITOR_DRAWN.read_only |
| a buffer edited, or saved (EDITOR_FILE_SAVED, FILE_WRITTEN; sprint 425) | EDITOR_DRAWN.unsaved |

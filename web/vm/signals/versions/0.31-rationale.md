## Layer 2 — Payload

DIFF_READ gains an optional `hunks`. `GET /api/session/<id>/diff?path=<rel>` reads one file's changes against the base the workspace read uses (main's merge-base, the default branch, the first commit, or none), and the record carries how many hunks it found; `files` is 1 when the file has changes, else 0. The whole-workspace read leaves `hunks` out. The editor needs the hunks for the inline changes, the status line's `+N −M vs main` and CHANGES IN THIS FILE (spec r6 §5, frame 24a; roadmap r8 E2). E1: no path or text in the payload.

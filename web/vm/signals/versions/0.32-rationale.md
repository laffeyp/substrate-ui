# v0.32 rationale — the inspector's drawn counts

*2026-11-09, sprint 422. Bumps v0.31 to v0.32 (135 tags, 134 live). One proposal: P-0.32-EDITOR-DRAWN-INSPECTOR.*

## Layer 2 — Payload

EDITOR_DRAWN gains required `outline_rows`, `hunks`, `activity_rows` and `history_rows`: the rows the inspector's OUTLINE, CHANGES IN THIS FILE, ACTIVITY and HISTORY sections draw (spec r6 §5.0, frame 24a; roadmap r8 E6). With no file open each is 0. EDITOR_HUNK_DRAWN (v0.28) carries each drawn hunk's author and line count. The pixel anchor gains a second row carrying these counts and the tab count with the same proc_seq (roadmap r8, "the anchor's room").

## Dual-contract pairing

| Behaviour | View-side counterpart |
|---|---|
| a file opened (EDITOR_FILE_OPENED; FILE_READ, DIFF_READ on the server) | EDITOR_DRAWN.outline_rows, hunks; EDITOR_HUNK_DRAWN per hunk |
| a session tool call on the file (ToolCall on the kernel record) | EDITOR_DRAWN.activity_rows |
| an edit, by the session or by hand (ToolResult ok; FileWritten) | EDITOR_DRAWN.history_rows |

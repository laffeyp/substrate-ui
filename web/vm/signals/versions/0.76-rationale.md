# Vocabulary 0.76 — P-0.76-SIGNAL-PATH-BATCHES

Sprint 532 (roadmap `2026-11-18-window-productionizing` r1, W10). Supersedes 0.75.

## Proposals

**P-0.76-SIGNAL-PATH-BATCHES** (new tags proposed): add `STREAM_BATCH_FOLDED` to the `stream` category and `TRANSCRIPT_ROWS_SKIPPED` to the `transcript` category.

**P-0.76-DEPRECATE-PER-ENVELOPE** (tag deprecation proposed): retire `STREAM_ENVELOPE_APPENDED` and `TRANSCRIPT_ROW_SKIPPED`, kept in the vocabulary with `deprecated_at: "0.76"` and `replaced_by`.

The window folds a pane's stream in per-animation-frame batches (sprint 524), so the trace carried one `STREAM_ENVELOPE_APPENDED` and one per-skip `TRANSCRIPT_ROW_SKIPPED` per envelope — tens of thousands of records on a long session. From 0.76 the controller emits one `STREAM_BATCH_FOLDED` per frame-batch with the envelope count and the batch's first and last kernel seq, and one `TRANSCRIPT_ROWS_SKIPPED` per batch with how many rows fell to each reason and the highest skipped seq. The per-envelope tags name an event the system no longer admits (the window never folds one envelope at a time), so no code emits them; they stay, retired, so a trace from before 0.76 still reads.

## Tags

- **STREAM_BATCH_FOLDED** (ambient, stream). Payload: `count` (envelopes folded in this frame's batch), `first_seq`, `last_seq` (the batch's first and last kernel Run seq, or `-1` if none carried a seq). Emit site: `web/vm/session_controller.ts` (`flushBatch`, once per frame; the non-rAF node path emits one per envelope).
- **TRANSCRIPT_ROWS_SKIPPED** (event, transcript). Payload: `count` (rows skipped in this batch), `reasons` (object: reason -> count, over `hidden_kind | folded | duplicate_seq | other`, as `TRANSCRIPT_ROW_SKIPPED` named them), `last_seq` (the highest kernel Run seq skipped in the batch, or `-1`). Emit sites: `web/vm/session_controller.ts` (hidden_kind, other, duplicate_seq, tool progress folded) and `web/reveal/transcript/Transcript.tsx` (tool results folded).

## Retired tags

- **STREAM_ENVELOPE_APPENDED** — `retired: true`, `deprecated_at: "0.76"`, `replaced_by: "STREAM_BATCH_FOLDED"`. Kept with its full payload and note.
- **TRANSCRIPT_ROW_SKIPPED** — `retired: true`, `deprecated_at: "0.76"`, `replaced_by: "TRANSCRIPT_ROWS_SKIPPED"`. Kept with its full payload and note; its `reason` enum (`TranscriptRowSkippedReason`) is still generated — `enum_fields` in `scripts/gen_signals.py` now walks all tags, not only live ones, because the replacement code reuses the reason values as the keys of `TRANSCRIPT_ROWS_SKIPPED.reasons`.

## Grounds

- **Project.** W10 productionizes the window's signal path: the page buffers its records and flushes to main once per burst, main writes the trace asynchronously, and the per-envelope tags become per-frame summaries. The T4 progress watchdog (sprint 535) answers "is the renderer keeping up with what it was last handed" by tracking a pane's highest appended seq (now `STREAM_BATCH_FOLDED.last_seq`) against its highest drawn/skipped seq (`TRANSCRIPT_ROW_DRAWN.seq` or `TRANSCRIPT_ROWS_SKIPPED.last_seq`); so each batch summary carries `last_seq`. The W1 gate (sprint 523) exercises the result: a 37,606-envelope session opens, draws to the bottom, and its trace holds 196 `STREAM_BATCH_FOLDED` (one per frame) with zero `TRACE_LOST` and zero `INVARIANT_BROKEN`.
- **SDD practice.** Hard rule 2: the vocabulary is the contract; the two new tags are proposed, ratified on the grounds, version-bumped, and recorded. `grammar/PRINCIPLES.md` `TAG_DEPRECATION_PROPOSED`: old names are retired explicitly, never silently removed, and the parity linter fails any code that emits a retired tag.
- **Engineering practice.** requestAnimationFrame batching of a streaming UI (the W2 envelope fold, sprint 524); the deprecate-then-remove discipline (TECHNIQUES.md #45), old names kept with a deprecation entry so prior traces still parse.

## Decision

Ratified. Two new live tags, two retired, `tag_count` 167 (164 live + 3 retired, with the pre-existing `SIGNAL_REJECTED`). `report_binding.rendered` carries `TRANSCRIPT_ROWS_SKIPPED` in place of the retired skip tag.

## Layer 2 — Payload

FILE_READ.encoding gains `utf8_bom`, `utf16` and `latin1`. The file API decodes a file by the rule the attachments use (sprint 446): a byte-order mark names UTF-8 or UTF-16; with none, a NUL byte in the first 8 KB is binary; otherwise UTF-8, and bytes that are not UTF-8 decode as Latin-1.

EDITOR_KEY_REFUSED.reason gains `not_utf8`: ⌘S on a file the editor opened read-only because its encoding is not plain UTF-8. The server's write refuses such a file; the editor does not send it.

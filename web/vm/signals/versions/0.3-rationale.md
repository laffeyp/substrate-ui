# v0.3 rationale — reveal shell vocabulary

v0.3 adds one tag to v0.2's thirty-five, from UI sprint 178. v0.2's tags carry over unchanged.

- **DELEGATE_CHILD_STARTED** (`runs`, event). A `delegate` call the session made now started a child session (kernel K323: every delegate child is a session whose parent is its caller). The controller reads the caller's children from the server while the call is open and announces each child created at or after the call's record time, once. The shell opens an interactive pane on it: a person writes a delegate child's next message, so its pane takes typing, unlike a run's.

It sits in `runs` beside `RUN_STARTED`: both open a pane for work the session handed off. A delegate child is not a held run, because its call returns only with its answer and nothing writes its end; so it has its own tag rather than a `RUN_STARTED` with no `TopologyRunEnded` to follow.

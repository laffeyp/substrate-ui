# v0.18 rationale — the lens field names the meta view's five lenses (sprint 368)

*Locked 2026-11-07. Supersedes `0.17.json`; 88 tags, 87 live. Earlier rationales cover everything not named here.*

## The change

**`P-0.18-LENS-SET`** (`PAYLOAD_FIELD_PROPOSED`). `LENS_CHANGED.lens` listed six values, one of them `graph`. The meta view has five lenses (`web/app/MetaView.tsx` `LENSES`; `GraphMode` in `web/vm/kinds.ts`). The stream lens draws the stream and its graph together, and its chip reads "stream+graph". So no lens change could carry `graph`, and the value is dropped. The field's values are now the lens set exactly: stream, structure, language, scene, io.

# v0.36 rationale — just an editor

## Layer 2 — Payload

FILE_WRITTEN.written gains `off_record`: the session's record could not take the edit (an ended session, or no record yet) and the file was written all the same, with `seq` null. EDITOR_OPENED.binding and EDITOR_DRAWN.binding gain `standard`, the default: a normal editor, with vim and nano as options. EDITOR_DRAWN.read_only is removed: no file is read-only. The anchor's third row takes a new layout (magic 0xB8): two bits of binding, no read-only bit. All from the Architect's rulings of 2026-11-09.

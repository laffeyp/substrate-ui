# v0.19 rationale — how a record opens, and which pages draw (sprint 371)

*Locked 2026-11-07. Supersedes `0.18.json`; 88 tags, 87 live. Earlier rationales cover everything not named here.*

## The changes

**`P-0.19-RECORD-HOW`** (`PAYLOAD_FIELD_PROPOSED`). `RECORD_OPENED.how` listed `records_page | deep_link | open_record`. The paths that attach a record read-only (`session_controller.ts` `attachRecordRoot`) are:
- File ▸ Open Record and ⌘O (`open_record`);
- a `substrate://record/` link (`deep_link`);
- a run pane showing its run's record, through `attachRun`, UI sprint 182 (`run`, new).

The records page opens sessions through `attachExisting`, not records, so `records_page` is dropped. `outcome` is decided by the record's stream: `attached` when it opens, `refused` when it errors or closes first. A missing record's 404 closes the stream.

**`P-0.19-PAGE-SET`** (`PAYLOAD_FIELD_PROPOSED`). `PAGE_DRAWN.page` listed `settings`. Settings is a dialog (`DIALOG_OPENED settings`, sprint 365), and no page draws it. The pages are records, assays and studio (`Surface` in `web/vm/kinds.ts`).

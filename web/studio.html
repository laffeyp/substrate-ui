topology name
producers + producer
a Producer brings a computation; "initial" Producers run on the run's opening cohort. emits = comma-separated event kinds.
views + view
a View is a running projection of the Bus a Predicate reads. KindCount(of) counts a kind; KindBuffer(of) buffers it.
triggers + trigger
a Trigger starts a Producer when its Predicate over a View matures. predicate: View <op> n (leave View blank for always).
routes + route
a Route stages an event of a kind into a future Producer's named input slot — carrying data into instances the Trigger will create.
termination policy
the TerminationPolicy ends the run. any_of / all_of compose member policies (OR / AND); add members below.
topology · node-graph drag the Producer cards; solid edges are Triggers, dashed are Routes
responder
model-backed Producers call the chosen Responder. deterministic = pure + seeded (no network, replay-stable); ollama = a real local LLM (fails loudly if not running).

# Rationale — signal vocabulary v0.6

*New file per no-in-place-edits. `0.5-rationale.md` stays on disk. v0.6 adds eight tags to pair with the substrate-side daily-driver session topology vocabulary locked at `substrate/process/signals/session-vocabulary.md` v0.1 (sprint 202, ratified 2026-08-25).*

---

## Per-change ledger (v0.6 vs v0.5)

### 1. Name collision resolved — `DRIVER_` prefix on the new driver-session tags

`SESSION_INIT` and `SESSION_ENDED` in v0.5 refer to the browser tab: `SESSION_INIT` anchors on page load; `SESSION_ENDED` fires on `beforeunload`. Substrate's `SessionStarted` / `SessionEnded` refer to a driver conversation lifetime, a different object with a different clock. Sprint 203's opening halt-and-articulate surfaced the collision. Architect ratified 2026-08-25 via option 1: the seven new tags for the driver-session concept carry the `DRIVER_` prefix, and the existing browser-side tags keep their names. v0.6 stays a strict superset of v0.5 — no rename to any prior emit site, no fixture breakage.

### 2. Seven new named tags — driver-session category

Category `driver_session` is new (v0.5 had 12 categories; v0.6 has 13). Each tag pairs one-to-one with a substrate-side kind from `session-vocabulary.md` v0.1 per TECH-SPEC-2026-08-25-round6 §13.5:

| substrate kind (v0.1) | ui tag (v0.6) | stratum | pane_id_scope |
| --- | --- | --- | --- |
| `SessionStarted` | `DRIVER_SESSION_STARTED` | event | session-open path in cockpit |
| `UserMessage` | `USER_MESSAGE_INJECTED` | event | chat input pane |
| `Park` | `PARK_LANDED` | event | transcript pane |
| `SessionEnded` | `DRIVER_SESSION_ENDED` | event | session-close path in cockpit |
| `TranscriptCompacted` | `TRANSCRIPT_COMPACTED_LANDED` | ambient | transcript pane |
| `SessionWarning` | `DRIVER_SESSION_WARNING_EMITTED` | incident | any pane subscribing to warnings |
| `SessionEndRequested` | `DRIVER_SESSION_END_REQUEST_ISSUED` | event | session-close path in cockpit |

### 3. One structural pairing — `ModelReply` → `PANE_SCROLLED`

Substrate's `ModelReply` is not paired with a named 1:1 event. What the UI actually observes is a transcript-pane repaint scrolling to accommodate the new reply. `PANE_SCROLLED` is new in v0.6 (pane category, event stratum) with `model_reply_ref: string` under `optional_payload` that carries the substrate seq of the `ModelReply` that triggered the scroll. When the field is set, the pairing is discharged; when absent, the scroll came from a keyboard/wheel/cursor source and no substrate-side kind pairs with it. This matches the shape of `EVENT_INSPECTED.kind` and `PRODUCER_INSPECTED.kind` — a substrate foreign key living in an optional payload slot.

Sprint 202's vocab doc §G named `PANE_SCROLLED` as "existing"; that was a naming error carried in from the tech spec draft. v0.5 has no such tag. v0.6 introduces it. Sprint 202's doc is updated in the same landing to say "PANE_SCROLLED (new in v0.6)".

### 4. `checkSessionBookends` — six grader invariants

The `invariants` block adds six clauses under the `checkSessionBookends` name (TECH-SPEC §10 requirement). All six are seq-based, not wall-time based — `t` is supplementary per substrate `0.1.json:15`.

- Every `DRIVER_SESSION_STARTED{session_id: S}` is followed by exactly one `DRIVER_SESSION_ENDED{session_id: S}` within record lifetime OR the substrate record status is `paused` at grader read time.
- No repeated `substrate.RunStarted` on one session_id across resumes.
- Every `USER_MESSAGE_INJECTED{session_id: S, turn_index: N}` reaches at least one `FinalAnswer` OR a `substrate.ProducerFailed` on the `model` producer within the same (S, N) pair; the topology's `turn_max_steps × model_timeout` ceiling bounds the wait.
- Every `PARK_LANDED{reason: final_answer}` is preceded within the same (session_id, turn_index) by exactly one `FinalAnswer` emit.
- `DRIVER_SESSION_WARNING_EMITTED` fires at most once per (session_id, condition_kind) pair.
- `TRANSCRIPT_COMPACTED_LANDED.dropped_seq_end < TRANSCRIPT_COMPACTED_LANDED.kept_seq_start` (contiguous drop range strictly below kept range).

# v0.7.3 rationale — dock-tag retirement

Ratified 2026-08-28 by Architect directive "why sit on blackboard, do
something about it." Agent-drafted Claude Opus 4.7 same day. Supersedes
v0.7.2.

## The change in one line

Eleven legacy-dock signal tags are retired. The lock drops from 69 tags
to 58. No other structural change.

## The eleven retired tags

| tag                        | last emit site (v0.7.2)                | why retired |
|----------------------------|----------------------------------------|-------------|
| TERMINAL_OPENED            | web/app.ts `termSetOpen`               | dock DOM gone |
| TERMINAL_CLOSED            | web/app.ts `termSetOpen`               | dock DOM gone |
| MODEL_SELECTED             | web/app.ts `_selectModel`              | dock picker gone; terminal-view picker fires DRIVER_PATCHED |
| PARAMS_CHANGED             | web/app.ts `_setParam`                 | dock params row gone; terminal-view row fires DRIVER_PARAMS_PATCHED |
| CHAT_ENTERED               | web/app.ts `runTerm chat` branch       | dock chat mode gone; session tags carry the flow |
| CHAT_EXITED                | web/app.ts `runTerm /exit` branch      | dock chat mode gone |
| TURN_SUBMITTED             | web/app.ts `runTerm` chat submit       | dock chat mode gone; USER_MESSAGE_INJECTED carries the flow |
| AGENT_LAUNCH_REQUESTED     | web/app.ts `sendChatMessage`           | /api/agent bridge gone from UI |
| AGENT_LAUNCHED             | web/app.ts `sendChatMessage`           | ditto |
| AGENT_TURN_STREAMED        | web/app.ts `streamAgentTurns`          | polling loop gone; SSE on /events replaces it |
| FINAL_ANSWER_RENDERED      | web/app.ts `streamAgentTurns`          | ditto |

Each tag had exactly one emit site in v0.7.2. All eleven sites lived
inside the dock code that sprint 037c deleted from `web/app.ts`.
POLL_TIMEOUT stays — followLive still uses it for launch/resume polling.

## What replaces them (already live)

- Session lifecycle: `DRIVER_SESSION_STARTED`, `USER_MESSAGE_INJECTED`,
  `PARK_LANDED`, `DRIVER_SESSION_ENDED` (sprint 035).
- Driver + params mutation: `DRIVER_PATCHED`, `DRIVER_PARAMS_PATCHED`
  (sprints 035t + 035v).
- Session-control tags: `BUNDLE_ATTACHED`, `WORKSPACE_SELECTED`,
  `TOOLS_RESTRICTED`, `ISOLATE_TOGGLED` (sprint 035w).

## What broke at the retirement

Nothing that outlived the same commit. Parity was 69/69 in v0.7.2; the
dock deletion drops emit sites for the eleven tags, so v0.7.3 drops them
from the lock. Vocab-parity reads clean at 58/58 (56 distinct emit
sites; unemitted tags are legal per the parity check).

Grader `tools/capture-grade.ts` shed two invariant checks that referenced
retired tags:
- `checkTurnInsideChatWindow` (TURN_SUBMITTED inside CHAT window).
- `checkAgentLaunchTerminate` (AGENT_LAUNCH_REQUESTED → AGENT_LAUNCHED |
  LAUNCH_REJECTED, then AGENT_LAUNCHED → exactly-one FINAL_ANSWER_RENDERED
  | POLL_TIMEOUT).
- `checkChatTurnCount` (CHAT_EXITED.turns_in_conversation).

The `EXPECTED_ORDER` list also shrinks by the same eleven tags. Session
bookends (`checkDriverSessionBookends`) and every other invariant hold.

## Not retired

- `POLL_TIMEOUT` — still emitted by `followLive` on launch/resume polling.
  Fixed 300s ceiling now (the dock's per-user timeout knob is gone).
- `LAUNCH_REJECTED`, `TOPOLOGY_LAUNCH_REQUESTED`, `TOPOLOGY_LAUNCHED`,
  `RESUMED`, `RESUME_REQUESTED`, `FETCH_FAILED`, `STUDIO_OPENED` — all
  live in launch/resume/incident paths that survived the dock deletion.
